# Interface languages / 界面语言

LayerHub supports **Simplified Chinese and English** throughout sign-in, navigation, jobs and printer queues, materials, printer controls, account/security settings and the slicing workbench. Choose a language on the sign-in form, in Personal account → Language, or with the language button in the header. Browser preferences determine the initial language; a saved account preference is applied after sign-in.

Account language also controls newly generated verification and job/material/device notification emails. Existing queued messages are not rewritten or resent. The independent cloud NAS-outage warning is bilingual because account preferences may be unreachable during an outage. Personal filenames, model/project names, member names and material records remain in their original language.

Changing language reloads the page. In the workbench, the current draft must be acknowledged as saved before the language preference is saved and the page reloads. Pending imports, gestures and uncertain/failed draft saves keep the current page. Other unsubmitted forms should be saved before opening language settings. Changing language never slices, prints, changes spool mappings or sends a notification.

## Maintaining translations

The browser needs no translation service or npm runtime. The release ships its generated catalog locally.

- `web/locales/en.json`: English translations with Chinese gettext-style message IDs.
- `I18n.t('…')`: fixed application copy; keep protocol IDs, domain values and user data outside it.
- ``I18n.msg`…${value}…` ``: plain-text messages with protected substitutions.
- ``I18n.html`<button>…${escapedValue}…</button>` ``: translate static text and human-facing attributes only. Continue escaping untrusted values with `esc()`; interpolation does not sanitize user content.
- `I18n.system(value)`: application-owned diagnostics and formatted server errors, never general user content.
- Native language names are intentionally retained in the language picker.

After editing copy or translations:

```sh
npm ci --prefix qa/frontend-deps --ignore-scripts
node qa/build-locales.cjs
node qa/build-locales.cjs --check
node --test qa/frontend.test.cjs qa/i18n.test.cjs qa/slicer-gizmo.test.mjs qa/face-placement.test.mjs qa/box-selection.test.mjs
```

The compiler records source offsets for text/title/placeholder/accessibility-label changes. HTML structure, classes, input names, values and protocol keys are retained. Generated HTML patches and the server's embedded English catalog are checked in CI. Preserve every substitution and printf token when translating. Regenerate the corresponding-source download and rebuild the binary after a catalog change.

## 简体中文

软件界面支持简体中文和 English，入口位于登录表单、顶部语言按钮及个人账户。登录前参考浏览器语言，登录后可读取账户偏好；选择后保存至账户及当前浏览器。新生成的验证码、任务、设备和耗材邮件采用账户语言，已排队的邮件不会重写或重发；NAS 独立掉线告警使用中英双语。

模型、文件、成员姓名、工程和料卷名称属于用户内容，保留原文。切换语言会刷新页面，工作台先等待草稿保存确认；保存失败、未确认或编辑仍在进行时保留页面，不切片、不启动打印。其他表单请先保存。

新增文案时维护 `web/locales/en.json`，按上面命令生成并检查语言包。应用文案使用 `I18n.t`、`I18n.msg` 或 `I18n.html`；不要翻译机器 ID、供料槽号、协议枚举或用户输入。HTML 插值仍须转义，翻译不替代输入校验。CI 检查缺失文案、占位符和生成文件；修改后同时重建程序与对应源码下载。
