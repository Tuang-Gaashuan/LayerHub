# Language settings / 语言设置

The software supports **English and Simplified Chinese**. Select a language on the sign-in form, use the header language button, or open **Personal account → Language**. Your initial language follows browser preferences; your account preference is saved on the server.

The interface covers jobs, queues, materials, printer controls, account/security settings and the model/slicing workbench. Dates, numbers and system errors follow the selected language. Future verification, print, material and printer emails use the recipient's account language. Existing queued emails are not rewritten or resent; the independent NAS outage warning is bilingual.

Filenames, model/project names, member names and material records remain as entered. Changing language reloads the page. The workbench waits for an acknowledged draft save first; a failed or uncertain save preserves your current page. Save other forms before switching. Language changes never start printing or change material mappings.

Translation maintenance: [source/I18N.md](source/I18N.md). No external translation service is used.

## 简体中文

登录表单、顶部语言按钮及“个人账户 → 语言”均可选择简体中文或 English。首次参考浏览器偏好，账户选择保存于服务器。

界面覆盖任务、队列、耗材、设备控制、账号与安全设置、模型和切片工作台；日期、数字和系统错误随语言显示。后续验证码与任务、耗材、设备邮件采用收件人的账户语言；已排队邮件不重写、不重发，NAS 独立掉线提醒为中英双语。

文件、模型、工程、成员及耗材名称保留原文。切换会刷新页面，工作台先等待草稿保存确认；失败或结果未确认时保留当前页面。其他表单请先保存。切换不会启动打印或修改供料映射，也不调用外部翻译服务。
